WORDFORGE 2.0 — ИНСТРУКЦИЯ

НОВЫЕ ФУНКЦИИ:
- Написание английского слова по русскому переводу.
- Восстановление слова с пропущенными буквами.
- Три уровня сложности: лёгкий, средний и сложный.

ОБНОВЛЕНИЕ НА GITHUB PAGES:
1. Распакуй архив WordForge-2.0.zip.
2. Открой свой репозиторий GitHub.
3. Выбери Add file → Upload files.
4. Перетащи ВСЕ файлы из распакованной папки в корень репозитория.
5. Подтверди замену файлов, если GitHub это предложит.
6. Нажми Commit changes.
7. Подожди 2–5 минут и обнови сайт.

СОХРАНЕНИЕ СЛОВ:
- Не удаляй репозиторий и не очищай данные браузера.
- Ключ словаря wordforge_words_v1 и формат записей оставлены без изменений.
- Существующие слова и статусы продолжат храниться в прежнем LocalStorage.
- Для дополнительной страховки сделай экспорт словаря до обновления.

ЕСЛИ ОТКРЫВАЕТСЯ СТАРАЯ ВЕРСИЯ:
1. Закрой WordForge.
2. Открой сайт в браузере и обнови страницу.
3. Если нужно, полностью закрой и снова открой браузер. Кэш сайта обновлён до wordforge-v2.

Слова хранятся локально в браузере на этом устройстве и не синхронизируются с другими устройствами.
